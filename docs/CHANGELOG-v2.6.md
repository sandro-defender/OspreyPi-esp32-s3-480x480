# Changelog v2.6 — Language Edition

## Screensaver language select (Georgian / English)

- New template select `screensaver_language` (`pages/screensaver.yaml`):
  options `Georgian` / `English`, `initial_option: Georgian`,
  `restore_value: true` — default stays Georgian, choice survives reboot.
- The `time_update` date lambda now picks between the existing Georgian
  weekday/month tables and new English ones:
  `ოთხშაბათი, 10 თებერვალი` ↔ `Wednesday, 10 Sep`
  (months abbreviated — full `Wednesday, 28 September` would be 487 px,
  wider than the screen; abbreviated longest is 363 px).
  No font change needed — `bold_geo_32` (DejaVu Sans Bold) already covers
  both alphabets.
- On-device UI: new `Saver lang` row on the Settings page
  (`settings_row_lang`, Georgian / English buttons, `select.set` on click),
  included in `apply_settings_theme` repaint and `update_settings_highlight`
  (active button glows like the theme/rotation buttons).
- Home Assistant entity: `select.<device>_screensaver_language`
  (`entity_category: config`). Changing it refreshes the date immediately.
- Settings mockups regenerated (`tools/generate_screenshots.py`) — only the
  5 settings PNGs changed.

## Excel pinout sheet

- New `hardware/PINOUT.xlsx` generated by `tools/generate_pinout_xlsx.py`:
  `Pinout` sheet (GPIO · used? · where connected · for what ·
  **my mapping** · **official docs** · notes, color-coded + autofilter),
  `Connectors` sheet (P1 / U9 / USB-C / FPC1 / BAT), `Readme` sheet
  (sources + official repo link).

## Hardware docs

- `hardware/`: ST7701S spec, YDP395BT003-V4 panel datasheet + CAD,
  vendor init-sequence text, official board/schematic/product images.
- New `hardware/README.md` folder index; official vendor repo links
  (`osptek/esp32-s3-touch-lcd-4`) in README, PINOUT.md, DEVICE_SPECS.md,
  wiki Hardware page.

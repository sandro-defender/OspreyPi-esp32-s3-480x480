# Hardware docs — OspreyPi / Osptek ESP32-S3-Touch-LCD-4 (ESP32-TPCB4)

Module **ESP32-S3-WROOM-1-N16R8** (ESP32-S3 · 16 MB Flash · 8 MB octal PSRAM),
3.95″ 480×480 ST7701S panel + FT6336U capacitive touch, SP3485EEN RS485,
CH340K USB-UART, IP5306 battery BMS, SGM6132 wide-range DCDC.

## ⚡ Pinout cheat sheet

- ✅ **Free:** GPIO40, GPIO41 (solder-only module pads)
- 🟡 **Expandable:** GPIO4/5 I²C sensor header (shared with touch, addr `0x38`)
- 🟡 **RS485-wired, unused by firmware:** GPIO1 (TX), GPIO2 (RX, input-only)
- 🔴 **Used:** 0, 3, 6–21 (RGB + sync), 38/39/45/47/48 (SPI init + control),
  13 (backlight), 42 (buzzer), 43/44 (USB-UART)
- ⛔ **Reserved:** 22–25 (don't exist), 26–34 (no pads), 35–37 (octal flash/PSRAM)

Full story: [`PINOUT.md`](PINOUT.md).
